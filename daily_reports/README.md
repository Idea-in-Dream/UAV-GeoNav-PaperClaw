今日遥感AI研究聚焦于3D高斯泼溅（3D Gaussian Splatting）与SLAM的融合，提出几何感知的在线建图方法，旨在提升实时定位与地图构建的精度和鲁棒性。该方法结合视觉惯性里程计与传统SLAM技术，利用3DGS的显式表示优化几何一致性，为复杂环境下的自主导航提供新思路。研究趋势显示，3DGS正从静态场景重建向动态在线SLAM应用拓展，强调几何约束与多传感器融合。

## ✨ 今日亮点

- 3DGS与SLAM结合，实现几何感知在线建图
- 融合视觉惯性里程计，提升定位鲁棒性
- 显式几何表示优化，增强地图一致性
